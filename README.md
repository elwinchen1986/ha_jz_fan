# 京造智能风扇 (JZ Smart Fan BLE)

Home Assistant 自定义集成，通过蓝牙 (BLE) 直接控制京造智能风扇，无需网关、无需云端，纯本地控制。

---

## 支持型号

以下型号共用同一 BLE 控制协议，均可使用本集成：

- **XD-2038FA**
- **XD-2988FA**
- **KF-2988A**

> 设备蓝牙广播名称通常包含 `BT2G` / `F008` 等标识。

---

## 功能特性

| 功能 | 实体类型 | 实体 | 说明 |
| --- | --- | --- | --- |
| 开关 / 调速 | `fan` | 风扇 | 12 档风速，映射为 0-100% |
| 左右摆头（快捷） | `fan` | 风扇 | oscillate 摆动开关 |
| 预设模式 | `fan` | 风扇 | 睡眠 / 自然 / 自选 / 3D循环 |
| 左右摆动角度 | `select` | 左右摆动角度 | 关闭 / 30° / 60° / 120° |
| 上下摆动角度 | `select` | 上下摆动角度 | 关闭 / 30° / 60° / 90° |
| 定时关机 | `select` | 定时关机 | 取消 / 1-15 小时 |
| 手动方向 | `button` | 上 / 下 / 左 / 右 | 瞬时微调风扇头朝向 |
| 指示灯 | `switch` | 指示灯 | 面板指示灯开关 |
| 语音提示 | `switch` | 语音提示 | 操作语音播报开关 |
| 蜂鸣器 | `switch` | 蜂鸣器 | 按键提示音开关 |

> 摆动角度与手动方向等控制需在风扇**已开机**状态下操作。

**预设模式说明：**

- **睡眠**：低风速档位（1-3 档）
- **自然**：模拟自然风（1-5 档）
- **自选**：手动自定义风速
- **3D循环**：立体循环送风

## 安装方式

### 方式一：HACS（推荐）

1. 安装 [HACS](https://hacs.xyz/)
2. HACS → 右上角三点菜单 → 自定义存储库
3. 仓库地址：`https://github.com/elwinchen1986/ha_jz_fan`，类别选择 **Integration**
4. 搜索并安装 **京造智能风扇**
5. 重启 Home Assistant

> HACS 依据 GitHub **Release** 判断更新。若更新代码后 HACS 未提示新版本，请确认已在 GitHub 发布对应版本的 Release。

### 方式二：手动安装

```bash
# 复制到 HA 配置目录的 custom_components 下
cp -r custom_components/jz_fan /path/to/your/ha/config/custom_components/
# 重启 HA
```

---

## 配置

1. 确保风扇已开机且蓝牙在 Home Assistant 主机可及范围内
2. **设置 → 设备与服务 → 添加集成**
3. 搜索 **京造智能风扇**
4. 从扫描到的蓝牙设备列表中选择你的风扇（名称含 `BT2G` / `F008` 等的会排在前面）
5. 确认添加即可

---

## 要求

- Home Assistant 2024.1.0 及以上
- 主机具备可用的蓝牙适配器，并已启用 Home Assistant 的 Bluetooth 集成

## 常见问题

| 问题 | 解决方案 |
| --- | --- |
| 扫描不到设备 | 确认风扇已开机、距离主机较近，检查蓝牙适配器是否正常 |
| 添加后不可用 | 稍等重连，或将主机靠近风扇后重载集成 |
| 控制无响应 | 确认风扇已开机；开启调试日志查看写入指令 |
| HACS 无更新提示 | 需在 GitHub 发布新版本 Release，HACS 才能识别 |

### 开启调试日志

在 `configuration.yaml` 中加入以下配置并重启，即可在日志中查看 BLE 连接、特征值发现与每次写入的指令：

```yaml
logger:
  default: info
  logs:
    custom_components.jz_fan: debug
```
